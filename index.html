About

Practical software that pairs AI with solid engineering.

I'm a BTech Computer Science engineer. My work runs from deep learning for computer vision, like plant disease detection with attention-augmented CNNs and sign language recognition, to LLM applications and RAG pipelines that answer from real data.

On the backend I build REST APIs with FastAPI. Right now I'm working on Project-X, a desktop app for interacting with AI, alongside a habit-tracking API and RAG experiments.

I like projects that are measured honestly: models compared against baselines, and code that someone else can clone and run.
